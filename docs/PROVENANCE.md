# Provenance, verification and inference

The proposed data are exact copies of the delivered brief, manifest and CSV files. The original manifest verifies its listed files; it does not independently authenticate external origin or itself. The release manifest verifies curated file consistency, and [file provenance](FILE_PROVENANCE.csv) connects copied code, tests, results, figures and PDFs to original audit hashes. [E01]

Core numerical source bytes are unchanged. The cache test has one portable root-path adaptation; the new verifier and release tests are separate orchestration. No private generating parameters, simulator repository, intended anomaly list or private verification were consulted or bundled. The package is selected evidence and research implementation, not a replica of every internal artifact.

The blind workflow separates delivered observations from generation knowledge. Original scoring reconstruction independently checks the recorded totals and rule. Controlled tests compare formulas, numerical identities, gradients, integration and failure states. These are internal computational checks. [E10] [MP04] [MP09]

Candidate bootstrap resamples quantify conditional sampling/estimation uncertainty with the chosen items/model fixed; fitted-reference simulations test a specified model procedure. Same-dataset sensitivity and agreement across methods are not independent empirical replication. None supplies an externally validated competence standard, real repeated-administration evidence or an external cohort. [MP05] [MP07] [MP09] [E08]

The claim index records every cited narrative location, original evidence IDs where available, packaged source, method, interpretation, qualification and validation status. A registry value is not necessarily a new scalar estimate: some entries are complete protocol/configuration groups or literal qualified source statements. Use the row's method and source details, rather than treating the number of indexed claims as a validity score.

Frozen previous-stage artifacts remain in the controlled workspace. The release retains enough selected evidence to inspect its principal claims and execute Tier 1. It explicitly does not include every component required by [Tier 2](FULL_REPLAY_PLAN.md). Internal clean-room, confidentiality and preservation evidence is deliberately kept outside the public-candidate directory.
